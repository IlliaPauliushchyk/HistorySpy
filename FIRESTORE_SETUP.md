# Настройка Firestore для футболистов и тренеров

## Описание

Данные футболистов и тренеров теперь загружаются из Firestore вместо локальных моков. Локальные моки остаются как fallback на случай, если Firestore недоступен.

## Структура данных в Firestore

### Коллекция `footballers`
- Документ `ru`: `{ names: string[] }` - русские имена футболистов
- Документ `en`: `{ names: string[] }` - английские имена футболистов
- Документ `be`: `{ names: string[] }` - белорусские имена футболистов

### Коллекция `coaches`
- Документ `ru`: `{ names: string[] }` - русские имена тренеров
- Документ `en`: `{ names: string[] }` - английские имена тренеров
- Документ `be`: `{ names: string[] }` - белорусские имена тренеров

## Загрузка данных в Firestore

### Способ 1: Из React Native приложения (рекомендуется)

1. Запустите приложение:
   ```bash
   npm run ios
   # или
   npm run android
   ```

2. В консоли разработчика (React Native Debugger или Chrome DevTools) выполните:
   ```javascript
   import { uploadMocksToFirestore } from '@/utils/firestore';
   await uploadMocksToFirestore();
   ```

3. Или создайте временный экран/кнопку в приложении для загрузки данных.

### Способ 2: Через временный экран

Можно добавить временную кнопку в приложение для загрузки данных:

```tsx
import { uploadMocksToFirestore } from '@/utils/firestore';

const handleUpload = async () => {
  try {
    await uploadMocksToFirestore();
    alert('Данные успешно загружены в Firestore!');
  } catch (error) {
    alert('Ошибка при загрузке данных: ' + error);
  }
};
```

## Как это работает

1. **Предзагрузка данных**: При запуске приложения данные автоматически предзагружаются из Firestore для текущего языка в фоновом режиме.

2. **Кэширование**: Данные из Firestore кэшируются в памяти для быстрого доступа.

3. **Fallback на моки**: Если данные из Firestore не загружены или недоступны, используются локальные моки.

4. **Синхронный доступ**: Функции `getFootballers()` и `getCoaches()` остаются синхронными и используют кэш или моки.

## Функции

### `uploadMocksToFirestore()`
Загружает все данные из локальных моков в Firestore для всех языков.

### `preloadDataFromFirestore(language)`
Предзагружает данные из Firestore для указанного языка в кэш.

### `getFootballers(language)`
Получает список футболистов для указанного языка. Использует кэш, если данные загружены из Firestore, иначе использует моки.

### `getCoaches(language)`
Получает список тренеров для указанного языка. Использует кэш, если данные загружены из Firestore, иначе использует моки.

### `clearFirestoreCache()`
Очищает кэш данных из Firestore.

## Примечания

- Кастомные наборы продолжают работать через AsyncStorage и не зависят от Firestore.
- Локальные моки (`src/mocks/`) не удаляются и используются как fallback.
- Данные автоматически предзагружаются при изменении языка приложения.

2.1. ЛОКАЛЬНОЕ ХРАНЕНИЕ (AsyncStorage)
---------------------------------------
Библиотека: @react-native-async-storage/async-storage версия 2.2.0

Данные, которые хранятся локально на устройстве пользователя:

A) Настройки игры (@gameSettings):
   - playersCount: количество игроков (число)
   - spiesCount: количество шпионов (число)
   - roundTime: время раунда в секундах (число или null)
   - infiniteTime: режим бесконечного времени (boolean)
   - setType: тип набора (игроки, тренеры, оба, или пользовательский набор)

B) Наборы данных (@sets):
   - removedPlayersNames: русские имена удаленных из базового списка игроков (массив строк)
   - removedCoachesNames: русские имена удаленных из базового списка тренеров (массив строк)
   - customSets: пользовательские наборы (массив объектов):
     * id: уникальный идентификатор набора
     * name: название набора (вводит пользователь)
     * items: элементы набора (массив объектов с name и type: 'player' | 'coach')
     * isCustom: флаг пользовательского набора (всегда true)
     * modifiedAt: временная метка последнего изменения (timestamp)
   - language: текущий язык интерфейса (один из 26 поддерживаемых языков)

C) Язык интерфейса (ключ 'language'):
   - Сохраняется выбранный пользователем язык приложения

ВАЖНО: 
- Все данные хранятся локально на устройстве пользователя
- Данные НЕ передаются на сторонние серверы (кроме Firebase для контента)
- Пользовательские наборы могут содержать имена футболистов и тренеров
- Никакие персональные данные пользователя не сохраняются

2.2. УДАЛЕННОЕ ХРАНЕНИЕ (Firebase Firestore)
---------------------------------------------
Библиотека: @react-native-firebase/firestore версия 23.7.0

Данные, загружаемые из Firestore:
- Коллекция 'footballers': списки имен футболистов для каждого языка (27 языков: ru, en, be, fr, de, zh, es, pt, hi, ar, az, bn, ur, id, ja, sw, ko, kk, ky, hy, it, tr, vi, nl, pl, uk, th)
- Коллекция 'coaches': списки имен тренеров для каждого языка (27 языков: ru, en, be, fr, de, zh, es, pt, hi, ar, az, bn, ur, id, ja, sw, ko, kk, ky, hy, it, tr, vi, nl, pl, uk, th)

Характеристики:
- Данные загружаются только для чтения
- Данные кэшируются локально после первой загрузки
- При смене языка данные перезагружаются из Firestore
- Приложение НЕ отправляет данные пользователя в Firestore (только чтение)

Данные НЕ отправляются в Firestore:
- Настройки игры пользователя
- Пользовательские наборы
- Любая информация о пользователе

2.3. ПАМЯТЬ ПРИЛОЖЕНИЯ (Redux Store)
-------------------------------------
Библиотека: @reduxjs/toolkit версия 2.11.1

Хранится в оперативной памяти во время работы приложения:
- Настройки игры (gameSettings)
- Состояние активной игры
- Выбранные наборы данных

ВАЖНО: Данные в Redux НЕ сохраняются после закрытия приложения
      Данные загружаются из AsyncStorage при запуске

4. РАЗРЕШЕНИЯ И ПРАВА ДОСТУПА
===============================================================================

4.1. ANDROID (AndroidManifest.xml)
-----------------------------------
Запрашиваемые разрешения:

A) INTERNET (обязательное)
   - Цель: подключение к Firebase Firestore для загрузки списков футболистов/тренеров
   - Обоснование: необходимо для основной функциональности приложения
   - Без этого разрешения приложение не сможет загружать данные из Firestore

ОТСУТСТВУЮТ следующие разрешения:
- ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION (геолокация)
- CAMERA (камера)
- RECORD_AUDIO (микрофон)
- READ_CONTACTS / WRITE_CONTACTS (контакты)
- READ_PHONE_STATE (информация о телефоне)
- READ_EXTERNAL_STORAGE / WRITE_EXTERNAL_STORAGE (хранилище)
- ACCESS_NETWORK_STATE (уже есть по умолчанию в Android)

Дополнительные настройки:
- android:allowBackup="false" - отключено резервное копирование данных
- android:supportsRtl="true" - поддержка RTL языков

4.2. iOS (Info.plist)
----------------------
Запрашиваемые разрешения:

A) NSLocationWhenInUseUsageDescription
   - ОПИСАНИЕ ПУСТОЕ (<string></string>)
   - ВАЖНО: Это разрешение присутствует, но НЕ ИСПОЛЬЗУЕТСЯ в коде
   - РЕКОМЕНДАЦИЯ: Удалить из Info.plist, так как геолокация не используется

Отсутствуют следующие разрешения:
- NSCameraUsageDescription (камера)
- NSPhotoLibraryUsageDescription (фотогалерея)
- NSMicrophoneUsageDescription (микрофон)
- NSContactsUsageDescription (контакты)
- NSBluetoothAlwaysUsageDescription / NSBluetoothPeripheralUsageDescription (Bluetooth)

Настройки безопасности:
- NSAppTransportSecurity:
  * NSAllowsArbitraryLoads: false (разрешены только HTTPS соединения)
  * NSAllowsLocalNetworking: true (разрешены локальные сети для разработки)

4.3. PRIVACY INFO (iOS PrivacyInfo.xcprivacy)
----------------------------------------------
Доступ к приватным API:

A) NSPrivacyAccessedAPICategoryFileTimestamp
   - Причина: C617.1 - "Управление приложением, которое вы предоставили"
   - Используется для: определение времени создания/изменения файлов (логи, кэш)

B) NSPrivacyAccessedAPICategoryUserDefaults
   - Причины: 
     * CA92.1 - "Функциональность вашего приложения"
     * 1C8F.1 - "Управление файлами, которые вы предоставили"
     * C56D.1 - "Сохранение состояния приложения"
   - Используется для: хранение настроек через UserDefaults (AsyncStorage)

C) NSPrivacyAccessedAPICategorySystemBootTime
   - Причина: 35F9.1 - "Аналитика производительности"
   - Используется для: Firebase Analytics (автоматическая аналитика производительности)

НЕ СОБИРАЮТСЯ ДАННЫЕ:
- NSPrivacyCollectedDataTypes: пустой массив
- NSPrivacyTracking: false (отслеживание пользователей отключено)

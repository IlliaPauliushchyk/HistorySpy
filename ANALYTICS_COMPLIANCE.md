# Анализ соответствия событий Firebase Analytics политике Google Play и политике конфиденциальности

## ✅ Безопасные события (не содержат PII)

### 1. События экранов

- `screen_view` - автоматическое событие Firebase
- ✅ Безопасно: содержит только названия экранов

### 2. Настройки игры (анонимные метрики)

- `game_started` с параметрами:
  - `players_count`, `spies_count`, `round_time` - числовые значения
  - `set_type` - тип набора (встроенный)
  - `language` - код языка
  - ✅ Безопасно: не содержит персональных данных

### 3. Выбор встроенных наборов

- `set_selected` для встроенных наборов (`set_type` из предопределенного списка)
- ✅ Безопасно: только системные названия наборов

### 4. Действия во время игры

- `card_shown`, `card_next`, `game_paused`, `game_resumed`
- `timer_edited`, `timer_restarted`
- `player_exiled`, `person_reselected`
- ✅ Безопасно: только индексы и роли, не персональные данные

### 5. Завершение игры

- `game_ended` с параметрами:
  - `winner`, `duration_seconds`, `cards_shown`
  - `set_type` - тип набора
  - `character` - имя футболиста из публичного списка
  - ✅ Безопасно: `character` - это публичная информация, не персональные данные пользователя

### 6. Язык и локализация

- `language_changed` с кодами языков
- ✅ Безопасно: только коды языков

### 7. Пользовательские свойства

- `preferred_language`, `preferred_set_type`
- `average_players_count`, `average_spies_count`
- `prefers_infinite_time`, `custom_sets_count`, `total_games_played`
- ✅ Безопасно: агрегированные анонимные метрики

## ✅ Решение проблемы кастомных наборов

### Аналитика для кастомных наборов полностью отключена

**Принятое решение**: Полное отключение аналитики для всех действий, связанных с пользовательскими (кастомными) наборами данных.

**Причины**:
- Пользователи могут вводить чувствительные данные в названия наборов (имена, email, телефоны и т.д.)
- Даже метаданные (количество элементов, типы) могут косвенно идентифицировать пользователя
- Максимальная защита конфиденциальности пользователей

**Реализация**:
- Все события для кастомных наборов возвращают `return` без отправки данных
- Удалены функции: `logCustomSetCreated`, `logCustomSetEdited`, `logCustomSetDeleted`
- События `logSetSelected`, `logSetInfoViewed`, `logSetEdited`, `logSetReset`, `logSetItemDeleted` не логируются для кастомных наборов
- События `logGameStarted`, `logGameEnded`, `logGameResultsViewed` не логируются, если используется кастомный набор

## 📋 Реализованное решение

### Аналитика для кастомных наборов полностью отключена

```typescript
// Все функции проверяют isCustom и возвращают return для кастомных наборов
export const logSetSelected = (params: {
  setType: string;
  setName?: string;
  isCustom: boolean;
  isModified: boolean;
}): void => {
  // Не логируем события для кастомных наборов (защита конфиденциальности)
  if (params.isCustom) {
    return;
  }
  // ... логика для встроенных наборов
};

// Аналогично для всех других событий
export const logGameStarted = (settings: GameSettingsData): void => {
  // Не логируем события для кастомных наборов (защита конфиденциальности)
  if (!isBuiltinSet(settings.setType) && settings.setType !== 'both') {
    return;
  }
  // ... логика для встроенных наборов
};
```

### Текущая формулировка:

> "Автоматические данные аналитики (если включены): информация об устройстве (модель, версия ОС), события использования приложения, технические метрики производительности"

### Рекомендуемая формулировка:

> "Автоматические данные аналитики (если включены):
>
> - Информация об устройстве (модель, версия ОС, разрешение экрана)
> - События использования приложения (открытие экранов, действия в игре, выбор настроек, использование встроенных наборов данных)
> - Технические метрики производительности (время загрузки, ошибки)
> - Анонимные метрики использования (количество игроков, выбранные встроенные наборы, язык интерфейса)
>
> **Важно**: Мы НЕ собираем имена пользователей, названия созданных пользовательских наборов, содержимое пользовательских наборов, email-адреса, телефонные номера или другую информацию, которая может идентифицировать вас лично.
>
> **Защита конфиденциальности пользовательских данных**: Аналитика полностью отключена для пользовательских (кастомных) наборов данных. Мы не отслеживаем создание, редактирование, удаление или использование пользовательских наборов, чтобы защитить вашу конфиденциальность."
